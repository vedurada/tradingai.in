# Database Schema — TradingAI.in

## Tables

### instruments
Core instrument master data. All market data references this table.

| Column | Type | Description |
|--------|------|-------------|
| id | SERIAL PK | Unique identifier |
| symbol | VARCHAR(20) | NSE/BSE symbol |
| name | VARCHAR(100) | Full name |
| type | VARCHAR(20) | index, stock, etf, commodity |
| exchange | VARCHAR(10) | NSE, BSE |
| segment | VARCHAR(20) | equity, derivatives |
| lot_size | INTEGER | Contract lot size |
| tick_size | DECIMAL | Minimum price increment |
| is_active | BOOLEAN | Active flag |

### market_quotes
Real-time and latest market quotes.

| Column | Type | Description |
|--------|------|-------------|
| id | BIGSERIAL PK | Unique identifier |
| instrument_id | INTEGER FK | References instruments |
| symbol | VARCHAR(20) | Quote symbol |
| price | DECIMAL(15,5) | Current price |
| change | DECIMAL(15,5) | Change from previous |
| change_pct | DECIMAL(10,4) | Percentage change |
| open | DECIMAL(15,5) | Open price |
| high | DECIMAL(15,5) | Day high |
| low | DECIMAL(15,5) | Day low |
| previous_close | DECIMAL(15,5) | Previous close |
| volume | BIGINT | Trading volume |
| open_interest | BIGINT | Open interest |
| market_status | VARCHAR(20) | Open/Closed |
| timestamp | TIMESTAMP | Quote timestamp |

### ohlcv
Historical OHLCV data. Partitioned by timeframe.

| Column | Type | Description |
|--------|------|-------------|
| id | BIGSERIAL PK | Unique identifier |
| instrument_id | INTEGER FK | References instruments |
| symbol | VARCHAR(20) | OHLCV symbol |
| timeframe | VARCHAR(10) | 1m, 5m, 15m, 1h, 1d |
| timestamp | TIMESTAMP | Bar timestamp |
| open/high/low/close | DECIMAL(15,5) | OHLC values |
| volume | DECIMAL(20,2) | Volume |
| UNIQUE | | (symbol, timeframe, timestamp) |

### option_contracts
Options contract data for option chains.

| Column | Type | Description |
|--------|------|-------------|
| id | SERIAL PK | Unique identifier |
| symbol | VARCHAR(20) | Underlying symbol |
| expiry | VARCHAR(20) | Expiry date |
| strike | DECIMAL(15,2) | Strike price |
| option_type | VARCHAR(2) | CE or PE |
| last_price | DECIMAL(15,5) | Last traded price |
| open_interest | BIGINT | Open interest |
| change_in_oi | BIGINT | Change in OI |
| volume | BIGINT | Volume |
| implied_volatility | DECIMAL(10,4) | IV |
| delta/gamma/theta/vega | DECIMAL(10,6) | Greeks |
| UNIQUE | | (symbol, expiry, strike, option_type) |

### option_chain_snapshots
Historical snapshots of complete option chains.

| Column | Type | Description |
|--------|------|-------------|
| id | BIGSERIAL PK | Unique identifier |
| symbol | VARCHAR(20) | Symbol |
| expiry | VARCHAR(20) | Expiry date |
| underlying_price | DECIMAL(15,5) | Underlying price |
| timestamp | TIMESTAMP | Snapshot timestamp |
| call_contracts | JSONB | Call contracts |
| put_contracts | JSONB | Put contracts |

### signals
Trading signals generated by the system.

| Column | Type | Description |
|--------|------|-------------|
| id | SERIAL PK | Unique identifier |
| symbol | VARCHAR(20) | Symbol |
| signal_type | VARCHAR(20) | Technical, OI-based, etc. |
| direction | VARCHAR(10) | BUY/SELL/HOLD/WATCH |
| confidence | DECIMAL(5,2) | 0-100 |
| entry/target/stop | DECIMAL(15,5) | Trade levels |
| strategy | VARCHAR(50) | Strategy name |
| status | VARCHAR(20) | OPEN/CLOSED |

### news
News articles and market events.

| Column | Type | Description |
|--------|------|-------------|
| id | SERIAL PK | Unique identifier |
| headline | VARCHAR(500) | Headline |
| source | VARCHAR(100) | News source |
| category | VARCHAR(50) | Markets, Economy, etc. |
| published_at | TIMESTAMP | Publication time |
| related_symbols | TEXT[] | Related symbols |
| ai_summary | TEXT | AI-generated summary |
| sentiment | VARCHAR(20) | Positive/Negative/Neutral |

## Indices

- `idx_instruments_symbol` on instruments(symbol)
- `idx_market_quotes_symbol_timestamp` on market_quotes(symbol, timestamp DESC)
- `idx_ohlcv_symbol_timeframe_time` on ohlcv(symbol, timeframe, timestamp DESC)
- `idx_option_contracts_symbol_expiry` on option_contracts(symbol, expiry)
- `idx_option_chain_snapshots_symbol_expiry` on option_chain_snapshots(symbol, expiry)
- `idx_signals_symbol_direction` on signals(symbol, direction)
- `idx_news_published` on news(published_at DESC)
