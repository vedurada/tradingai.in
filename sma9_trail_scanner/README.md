# SMA9 Trail Trail Scanner

Trailing-stop variant of the sma9 scanner. Entry logic inherited from sma9; exit uses a 5-point trailing stop (activates at +5, stop = peak - 5).

Database: /opt/tradingai/database/sma9_trail.db
Service: tradingai-sma9-trail-scanner
API: /api/sma9-trail/*
Dashboard: https://tradingai.in/live/sma9-trail/
