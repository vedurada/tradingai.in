# SMA3 Trail Trail Scanner

Trailing-stop variant of the sma3 scanner. Entry logic inherited from sma3; exit uses a 5-point trailing stop (activates at +5, stop = peak - 5).

Database: /opt/tradingai/database/sma3_trail.db
Service: tradingai-sma3-trail-scanner
API: /api/sma3-trail/*
Dashboard: https://tradingai.in/live/sma3-trail/
